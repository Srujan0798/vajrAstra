## 1. Validation set clarification (re-read user task)

User task: "McNemar test on 160 validation items (80 per lang × 2 langs)".

The 80 per lang is NOT the same as the 80/10/10 split (which gives only 20 per lang). The 80-per-lang comes from probe22's full image set:

|---|---|---|
| kok | `manifest.json` filter `language='kok'` | **100** |
| pa  | `manifest.json` filter `language='pa'`  | **100** |

McNemar requires paired predictions on the SAME items for both engines. We therefore use the full 100 per lang = 200 paired items for the McNemar gate (matches probe22 already banked), and report:

- **Primary McNemar:** 200 paired items (kok=100 + pa=100).
- **Secondary "validation 160":** user's 80 × 2 = 160 — derived by holding out 20 per lang (the test split from `QLORA_TRAINING_DATA.md` §2). This is the held-out subset the user asked for explicitly.

Both analyses must agree (or the disagreement is the verdict's job to explain).

### 1.1 Pairing (required for McNemar)

The 200 paired items are identified by `image_id`. For each item, generate TWO predictions:

1. **QLoRA output** — `Qwen2.5-VL-3B @ 4-bit + <lang>_qlora_adapter`.
2. **Wrap baseline output** — `Qwen2.5-VL-3B @ 4-bit WITHOUT adapter` (proxy for "zero-shot VLM").

Both predictions use the same `image_path` + same prompt. Difference is only the adapter presence.

### 1.2 Why paired predictions matter

McNemar exact test (binomial) operates on a 2×2 table of who-got-it-right:

```
                       wrap_correct   wrap_wrong
qlora_correct             a             b
qlora_wrong               c             d
```

Test statistic uses the discordant cells (b, c) only. Same items must be scored by both engines — image_id is the join key.

## 3. CER computation (paired)

Per item: `cer(gt, pred)` using the existing `level2/probe22/metrics.py` `cer` function (already handles ctrl-char strip per §6.5 + space-forgery patch). For empty predictions: CER=1.0 (silence is failure, not skip).

Per-lang aggregate:
- mean CER (capped at 1.0; uncapped also reported for hallucination check).
- per-item CER vector for McNemar.

Then convert each per-item CER into a binary "win/loss" against a threshold for the McNemar 2×2 table:

- **threshold:** `CER <= 0.5` is "correct" (binary). Tunable; default 0.5.
- Rationale: for Indic OCR with average CER ~0.15-0.45, the 0.5 threshold separates "useful" from "broken" — see Lane A evidence + W6 §5 expectation.

Two binary vectors (per item): `qlora_correct[i]`, `wrap_correct[i]`. McNemar operates on the discordant count.

## 4. McNemar exact test (primary K1 gate)

```python
from scipy.stats import binom   # OR: use mlx-tune built-in if it provides it
# OR: implement exact2x2 via Fisher-style mid-p test for (b, c)

# discordant
b = sum((qlora_correct[i] is False) and (wrap_correct[i] is True)  for i in items)  # wrap wins
c = sum((qlora_correct[i] is True)  and (wrap_correct[i] is False) for i in items)  # qlora wins

# McNemar exact (binom test, two-sided)
# null: p(b) = p(c) = 0.5
n = b + c
if n == 0:
    p_value = 1.0
else:
    p_value = binom.cdf(min(b, c), n, 0.5) * 2  # two-sided
    p_value = min(p_value, 1.0)
```

Per-lang verdict:
- If `p_value < T1 = 0.05` AND `qlora_correct_count > wrap_correct_count` AND CER delta ≥ T2 = 3.0pt → **K1 SURVIVES** for that lang.
- Else → **K1 KILLED** for that lang → drop adapter from W6 routing.

## 6. Wilson 95% CI (per-lang CER)

For each (engine, lang) cell, compute Wilson 95% CI on the per-item binary "CER ≤ 0.5" outcome:

```python
from statsmodels.stats.proportion import proportion_confint
wilson_lo, wilson_hi = proportion_confint(
    count=successes,
    nobs=n,
    alpha=0.05,           # 95% CI
    method='wilson'
)
```

## 9. Eval script pseudocode

`eval_qlora.py` (new file, Miss agent applies):

```python
import json, mlx.core as mx
from pathlib import Path
from mlx_vlm import generate
from metrics import cer                       # existing level2/probe22/metrics.py
from scipy.stats import binom
from statsmodels.stats.proportion import proportion_confint

LANGS = ['kok', 'pa']
WRAP_MODEL = 'mlx-community/Qwen2.5-VL-3B-Instruct-4bit'
ADAPTER_DIR = Path('/w6/out')
EVAL_ROOT = Path('level2/probe22/w6_eval')
SPLIT_FILE = Path('level2/probe22/w6_data/{lang}_sft.jsonl')

def load_items(lang):
    rows = []
    with open(SPLIT_FILE.format(lang=lang)) as f:
        for line in f:
            rows.append(json.loads(line))
    return rows

def predict(model, adapter, image_path, prompt, max_tokens=1024):
    if adapter is None:
        text = generate(model, image=image_path, prompt=prompt, max_tokens=max_tokens, temperature=0)
    else:
        text = generate(model, image=image_path, prompt=prompt, adapter=str(adapter),
                        max_tokens=max_tokens, temperature=0)
    return text

def evaluate_lang(lang):
    items = load_items(lang)
    adapter = ADAPTER_DIR / f'{lang}_qlora'
    wrap_preds, qlora_preds = [], []
    for it in items:
        prompt = f"<lang={lang}>; transcribe the Indic text in the image"
        wrap_preds.append({'image_id': it['image_id'], 'prediction': predict(WRAP_MODEL, None, it['image_path'], prompt)})
        qlora_preds.append({'image_id': it['image_id'], 'prediction': predict(WRAP_MODEL, adapter, it['image_path'], prompt)})

    # CER per pair
    paired = []
    for w, q in zip(wrap_preds, qlora_preds):
        gt = next(i['gt'] for i in items if i['image_id'] == w['image_id'])
        cer_w = cer(gt, w['prediction'])
        cer_q = cer(gt, q['prediction'])
        paired.append({'image_id': w['image_id'], 'cer_wrap': cer_w, 'cer_qlora': cer_q,
                       'wrap_correct': cer_w <= 0.5, 'qlora_correct': cer_q <= 0.5})

    # McNemar exact
    b = sum(1 for p in paired if (not p['qlora_correct']) and p['wrap_correct'])
    c = sum(1 for p in paired if p['qlora_correct'] and (not p['wrap_correct']))
    n = b + c
    if n == 0:
        p_value = 1.0
    else:
        p_value = min(binom.cdf(min(b,c), n, 0.5) * 2, 1.0)

    # CER means
    cer_wrap = sum(p['cer_wrap'] for p in paired) / len(paired)
    cer_qlora = sum(p['cer_qlora'] for p in paired) / len(paired)
    delta = cer_qlora - cer_wrap  # negative = improvement

    # K1 verdict
    if p_value < 0.05 and delta < -0.03 and c > b:
        verdict = 'SURVIVES'
    elif c == b == 0:
        verdict = 'KILLED'
    else:
        verdict = 'KILLED'

    # Wilson 95% CI
    n_total = len(paired)
    wrap_correct_n = sum(p['wrap_correct'] for p in paired)
    qlora_correct_n = sum(p['qlora_correct'] for p in paired)
    wrap_lo, wrap_hi = proportion_confint(wrap_correct_n, n_total, alpha=0.05, method='wilson')
    qlora_lo, qlora_hi = proportion_confint(qlora_correct_n, n_total, alpha=0.05, method='wilson')

    return {
        'lang': lang,
        'cer_wrap': cer_wrap,
        'cer_qlora': cer_qlora,
        'cer_delta': delta,
        'mcnemar_b': b, 'mcnemar_c': c, 'mcnemar_n': n, 'mcnemar_p': p_value,
        'wilson_wrap': [wrap_lo, wrap_hi],
        'wilson_qlora': [qlora_lo, qlora_hi],
        'k1_verdict': verdict,
        'routing_decision': 'include_qlora' if verdict == 'SURVIVES' else 'wrap_only'
    }

def main():
    summary = {}
    for lang in LANGS:
        r = evaluate_lang(lang)
        out = EVAL_ROOT / lang
        out.mkdir(parents=True, exist_ok=True)
        for fn, data in [('paired_metrics', r), ('mcnemar', r), ('wilson_ci', r), ('k1_verdict', r)]:
            (out / f'{fn}.json').write_text(json.dumps(data, indent=2, ensure_ascii=False))
        summary[lang] = r
    summary['w6_q_lora_winners'] = [l for l,r in summary.items() if r['k1_verdict'] == 'SURVIVES']
    summary['w6_wrap_only_langs'] = [l for l,r in summary.items() if r['k1_verdict'] != 'SURVIVES']
    (EVAL_ROOT / 'summary.json').write_text(json.dumps(summary, indent=2, ensure_ascii=False))
    print(json.dumps(summary, indent=2, ensure_ascii=False))

if __name__ == '__main__':
    main()
```
