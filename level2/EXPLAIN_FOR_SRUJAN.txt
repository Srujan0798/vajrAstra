WHAT IS GOING ON (Level 2) — own this explanation

GOAL
  Vaultstack needs Indian OCR outputs on OUR South pages.
  Those outputs = benchmarks.
  Later we find gaps and train to beat/close them.

METHOD (best way for OSS OCR)
  Same as official Tesseract usage:
    page image -> tesseract -l tel/tam/kan/mal -> text
  Our script only:
    1) turns PDF/PNG page into an image
    2) calls the OCR engine
    3) saves Level-1-style JSON under level2/out/<engine>/

  So: NOT a different OCR. Automation for 400 pages + JSON packaging.

FIVE ENGINES
  1. tesseract_indic     <- running now on main .venv
  2. easyocr             <- install on .venv311
  3. openbharatocr       <- install on .venv311 (ID-card lib; full pages may fallback)
  4. indicphotoocr       <- install on .venv311
  5. paddleocr_indic     <- install on .venv311 (needs Python 3.11, not 3.14)

WHY TWO VENVS
  Your main .venv is Python 3.14.
  PaddleOCR / IndicPhotoOCR need Python 3.11 wheels.
  So:
    .venv     = Tesseract run
    .venv311  = other engines

LOOP UNTIL DONE
  Script: level2/continue_all_engines.sh
  Re-run / loop this until each engine has 400 JSON files.
  Safe to re-run (uses --skip-existing).

DO NOT TOUCH
  arc_level_1/  (Level 1 archive — leave it)
