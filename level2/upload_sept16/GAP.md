## Method / approximation notes (explicit)

- Volume gap counts WRONG chars as captured and caps per-page capture at
  GT length -> **lower bound**. Uncapped pooled max (0.2% gap,
  over-capture on 96 pages) is the literal spec formula; it is in
  the per-script table too, so nobody quotes it by accident.
- GT = raw text layer, stripped; no normalization (this is volume, not
  correctness — see CER_STAGE3B.json for character error rates).
- Basis (177 pages) = the same set LEADERBOARD_BY_SCRIPT.md
  uses for capture medians; Malayalam has only 9 usable-layer pages (77 total).
- l1_chars (Level-1 gold labels) total over all 400 pages: 552,535.
- Pooling uses all 10 packs on disk, incl. openbharatocr (= tesseract_indic
  alias) and rapidocr (ml bucket partial_wash) — max-pooling can only
  inflate capture, so the gap stays a lower bound regardless.
- Legacy/broken census (headline 4) recomputed here from disk: legacy =
  layer sane but majority engine-output script differs from layer script;
  broken = private-use/control chars > 0.5% of layer. Matches the earlier
  L2 finding exactly (63 legacy / 43 broken on the same 177-page basis).
