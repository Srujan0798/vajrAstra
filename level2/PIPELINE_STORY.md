# PIPELINE STORY — "Explain like I own it" (Level 2)

_The 3-minute version Srujan can tell the team, every fact traceable to a file on disk._

## What we built
One command runs the whole benchmark. `level2/orchestrator.py` is the control tower:
it watches every OCR engine fill, kills stalled runs, respawns what's incomplete,
migrates finished outputs into the seal structure, verifies everything against
ground truth, and regenerates all reports — counts always from disk, never hand-written.

```
status   → what's done/stalled (disk truth)
fill     → respawn incomplete engines in parallel (disk + core + spawn guards)
migrate  → out/<engine>/ → models/<engine>/json/
verify   → verify_all.py + verify_v2.py
dashboard→ DASHBOARD.md (counts, speed, ETA)
autoloop → all of the above every 30 min, unattended
seal_gen → models/<eng>/RUN.md + metrics + reports/LEVEL2_SEAL.md
```

## The 400 pages
`level2/pages_manifest.json` — same 400 pages as Level 1 (100 per language:
te/ta/kn/ml), each with `dominant_script` and a `mixed_book_page` flag.
The flag matters: work/ books include Telugu-medium Maharashtra textbooks, so
some pages are Hindi/Marathi/English. Policy is OPEN — engines must read
whatever glyphs are on the page. The lang tag is an ID, not a constraint.

## The engines (10, free/open-source, Indian-relevant)
Two Python venvs because paddle/easyocr/surya/doctr need 3.11, tesseract runs on 3.14.
Each engine gets the same PNG renders (`level2/renders_shared/`) and produces the same
JSON pack shape as Level 1. Every page is timed (`HEARTBEAT.jsonl`) — crash-survivable.

## Verification (the main labor — every page, not sampling)
- **verify_all.py**: every pack vs the PDF text layer (free GT): empty? short?
  capture ratio? script mismatch?
- **verify_v2.py**: cross-engine consensus (≥6/10 engines agree a page has text),
  repetition loops, charset hallucination, English-leak on Indic pages, native
  digits, NFC compliance, JSON schema, runtime, duplicate-output collapse.
  → `reports/VERIFY_V2_SUMMARY.json`, `reports/LEADERBOARD.md`, `reports/FAILURE_TAXONOMY.md`

## What the numbers say (12 Sep, from disk)
- 9/10 engines at 400/400; easyocr blocked by a reader-combo bug (guarded, not spam-respawned).
- surya leads total output (461K chars); tesseract stack leads speed+capture balance (91.5% of L1 volume).
- doctr's Latin-only model leaks English on 263 Indic pages — honest weakness, recorded.
- kn_035/kn_074 are the same page in two PDFs (duplicate audit caught it).
- Consensus: 367/400 pages have ≥6 engines producing text — solid pseudo-GT base.

## Seal law (why nothing is deleted)
Old runs move to `out_archive/<engine>_vN_<reason>/` with READMEs. Counts in
reports/LEVEL2_SEAL.md are generated by `seal_gen.py` from disk — no hand numbers.
LEVEL 3 (paid APIs) does not start until LEVEL2_SEALED = true.

## If someone asks "why is X empty?"
Open `reports/FAILURE_TAXONOMY.md` — empty/loop/garbage/leak/lines-short per
engine — then `reports/REVIEW_QUEUE.md` for the pages where engines disagree most.
