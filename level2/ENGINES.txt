LEVEL 2 — Indian OCR outputs on same Dataset pages

Goal
  Run OSS Indic OCR engines on the same pages as Level 1.
  Save Level-1-style JSON packs. Those outputs are what can be kept as benchmarks.

Engines (5)
  1. tesseract_indic
  2. indicphotoocr
  3. openbharatocr
  4. paddleocr_indic
  5. easyocr

Folders
  prompts/                 20 batch prompts (same page splits as Level 1)
  out/<engine>/{te,ta,kn,ml}/   JSON outputs
  pages_manifest.json      all 400 page targets

How to assign
  For EACH engine, run all 20 prompts (or script the engine over all pages).
  Example: first finish tesseract_indic for all batches, then indicphotoocr, etc.

Do not touch arc_level_1/ (Level 1 archive stays as-is).
